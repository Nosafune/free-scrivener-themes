# Free Scrivener Themes

Finished Windows Scrivener 3.x themes.

## Themes

- `themes/mani_katti.scrtheme`
- `themes/salva_la_reina.scrtheme`
- `themes/majima.scrtheme`

## Install

Import a theme in Scrivener via:

`Window > Themes > Import Themes`
