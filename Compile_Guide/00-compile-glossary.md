# Compile Glossary

## Compile

The process of exporting some or all of a Scrivener project into an external file or printable output.

## Compile For

The output destination or file type, such as Word, PDF, EPUB, RTF, plain text, or print.

## Compile Format

A reusable package of export formatting rules. A Compile Format contains Section Layouts and formatting behavior.

## Section Type

A label that tells Scrivener what a Binder item is.

Examples:

- Chapter
- Scene
- Part
- Appendix
- Front Matter
- Title Page

Section Types belong to the project.

## Section Layout

A formatting recipe inside a Compile Format.

Examples:

- chapter title with page break
- numbered heading
- plain scene text
- appendix heading
- section title only

Section Layouts belong to the selected Compile Format.

## Assign Section Layouts

The mapping step where you tell Scrivener which layout should apply to each Section Type.

## Contents

The list of Binder documents included in the current compile operation.

## Placeholder

A special token that Scrivener replaces during compile.

Examples:

- `<$projecttitle>`
- `<$author>`
- `<$p>`
- `<$n>`
- `<$wc>`

## Replacement

A compile-time text substitution.

Useful for:

- placeholder simplification
- manuscript cleanup
- edition-specific wording
- symbol replacement
- formatting transformations

## Metadata

Project-level or document-level information used during compile.

Examples:

- title
- author
- description
- custom fields
- ebook metadata

## As-Is

A layout or compile behavior that preserves the formatting already present in the Editor instead of overriding it through Compile.
