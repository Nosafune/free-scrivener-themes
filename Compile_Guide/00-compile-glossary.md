# Compile Glossary

## Compile

The process of exporting some or all of a Scrivener project into an external file or printable output.

## Compile For

The output destination or file type: Word, PDF, EPUB, RTF, plain text, or print.

## Compile Format

A reusable package of export formatting rules. A Compile Format contains Section Layouts and controls formatting behavior at export time. Formats can be project-specific or shared across projects.

## Section Type

A label that tells Scrivener what a Binder item is. Section Types belong to the project.

Examples: Chapter, Scene, Part, Appendix, Front Matter, Title Page.

## Section Layout

A formatting recipe inside a Compile Format that defines how a particular type of document appears in output.

Examples: chapter title with page break, numbered heading, plain scene text, appendix heading, section title only.

Section Layouts belong to the selected Compile Format, not to the project.

## Assign Section Layouts

The mapping step in Compile where you tell Scrivener which layout applies to each Section Type.

## Contents

The list of Binder documents included in the current compile operation. Controlled by the compile group, include/exclude checkboxes, and front/back matter settings.

## Placeholder

A special token that Scrivener replaces during compile with project data, numbering, dates, or other generated content.

Examples: `<$projecttitle>`, `<$author>`, `<$p>`, `<$n>`, `<$wc>`, `<$date>`.

## Replacement

A compile-time text substitution defined by you. Useful for placeholder readability aliases, draft-marker cleanup, edition-specific wording, and symbol conversion.

## Metadata

Project-level or document-level information used during compile: title, author, description, custom fields, ebook metadata.

## Separator

What appears between compiled Binder items in the output: nothing, a blank line, a page break, a symbol, or custom text.

## As-Is

A Section Layout option or compile behavior that preserves the formatting already in the Editor instead of overriding it. Useful for title pages, front matter, and specially formatted documents.

## Compile Format Designer

The advanced panel where you edit the internals of a Compile Format: Section Layout definitions, title options, separators, style behavior, transformations, page settings, and compatibility rules.
