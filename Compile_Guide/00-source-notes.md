# Source Notes

This package is a documentation draft, not a replacement for the official Scrivener manual.

For final publication, verify:

- current Scrivener version behavior
- Windows/macOS differences
- exact menu names
- output-format limitations
- placeholder syntax
- ebook behavior
- compile format availability

Recommended official checks inside Scrivener:

- Help → Scrivener Manual
- Help → List of All Placeholders
- File → Compile
- Project → Project Settings → Section Types

Editorial standard for the finished book:

- use screenshots from the target Scrivener version
- distinguish macOS and Windows where behavior differs
- test every workflow in a clean sample project
- include before/after screenshots for every Compile outcome
