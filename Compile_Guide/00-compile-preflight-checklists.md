# Compile Preflight Checklists

Use these before a serious export.

## Universal preflight

- [ ] Project has a current backup.
- [ ] Output format is selected intentionally.
- [ ] Compile group is correct.
- [ ] Contents list includes only intended material.
- [ ] Front matter and back matter are correct.
- [ ] Section Types are assigned.
- [ ] Section Layouts are assigned.
- [ ] Title page metadata is correct.
- [ ] Comments and footnotes behavior is intentional.
- [ ] Replacements are reviewed.
- [ ] A short test compile has been inspected.

## Word manuscript

- [ ] Standard manuscript format selected or customized.
- [ ] Double spacing checked if required.
- [ ] First-line indents checked.
- [ ] Chapter breaks checked.
- [ ] Headers/footers checked.
- [ ] Footnotes/endnotes checked.
- [ ] Comments removed unless needed.
- [ ] File opened in Word or compatible processor.

## PDF

- [ ] Page size checked.
- [ ] Margins checked.
- [ ] Header/footer checked.
- [ ] Page numbering checked.
- [ ] Front matter numbering checked.
- [ ] Fonts checked.
- [ ] PDF viewed outside Scrivener.

## Ebook

- [ ] EPUB/Kindle format selected.
- [ ] Cover selected if needed.
- [ ] Metadata complete.
- [ ] Table of contents checked.
- [ ] Chapter navigation checked.
- [ ] Images sized appropriately.
- [ ] Front matter and start location checked.
- [ ] Ebook validated or tested in a reader.

## Plain text

- [ ] Formatting expectations reduced.
- [ ] Separators checked.
- [ ] Markdown/MultiMarkdown behavior checked if applicable.
- [ ] Smart quotes and special characters checked.
- [ ] Replacements reviewed.
