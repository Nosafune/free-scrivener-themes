# Compile Preflight Checklists

Use these before a serious export. Run the universal checklist every time, then the format-specific checklist for your target output.

## Universal preflight

- [ ] Project has a current backup.
- [ ] Output format is selected intentionally (Compile For).
- [ ] Compile Format is selected and named clearly.
- [ ] Compile group or Contents are correct.
- [ ] Contents list includes only intended material.
- [ ] Front matter and back matter are present and correct.
- [ ] Section Types are assigned to all Binder items that will compile.
- [ ] Section Layouts are assigned to all used Section Types.
- [ ] Title page metadata is correct.
- [ ] Comments and footnotes behavior is set intentionally.
- [ ] Replacements are reviewed.
- [ ] A short test compile has been inspected externally.

## Word manuscript

- [ ] Standard manuscript format selected or customized.
- [ ] Double spacing confirmed if required.
- [ ] First-line indents confirmed.
- [ ] Chapter breaks appear correctly.
- [ ] Headers and footers checked.
- [ ] Footnotes/endnotes confirmed.
- [ ] Comments removed unless needed for editorial pass.
- [ ] File opened and inspected in Word.

## PDF

- [ ] Page size confirmed (Letter vs A4 vs trim size).
- [ ] Margins confirmed.
- [ ] Header and footer confirmed.
- [ ] Page numbering confirmed.
- [ ] Front matter numbering checked.
- [ ] Fonts confirmed.
- [ ] PDF viewed outside Scrivener before finalizing.

## EPUB / Ebook

- [ ] EPUB format selected (Scrivener 3 exports EPUB 3).
- [ ] Cover image selected.
- [ ] Ebook metadata complete (title, author, description).
- [ ] Table of contents checked.
- [ ] Chapter navigation confirmed.
- [ ] Images sized appropriately.
- [ ] Front matter and reading start location checked.
- [ ] Ebook tested in Calibre, Kindle app, or a real reader.

## Plain text

- [ ] Formatting expectations are realistic for the format.
- [ ] Separators checked.
- [ ] Markdown or MultiMarkdown behavior checked if applicable.
- [ ] Smart quotes and special characters confirmed.
- [ ] Replacements reviewed for plain-text safety.
