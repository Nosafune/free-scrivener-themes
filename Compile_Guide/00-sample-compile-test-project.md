# Sample Compile Test Project

Use this structure as a controlled test bed for learning compile settings and for screenshots.

## Binder structure

```
Front Matter
  Title Page
  Copyright
  Dedication

Manuscript
  Part One
    Chapter One
      Scene 1
      Scene 2
    Chapter Two
      Scene 1
      Scene 2
  Appendix A

Back Matter
  Acknowledgments
  About the Author
```

## Test content to include

Add at least one of each:

- footnote
- comment / inline annotation
- image
- table
- custom metadata field
- styled paragraph (block quote, verse, or similar)
- placeholder token
- replacement token

## Why this structure works

A small controlled project makes every compile concept observable. You can see exactly what happens when:

- a Section Type changes on one document
- a Section Layout changes on one type
- a separator rule changes between scenes
- a placeholder resolves at export time
- a comment is included or excluded
- front matter is included or excluded

## Using this for format testing

Compile the test project to multiple output formats in sequence. Use a fresh copy for each experiment so results are clean.

## Numbering test tip

For automatic numbering tests, use at least three consecutive chapters so you can verify stream continuity, restart behavior, and front-matter exclusion in one compile.
