# Sample Compile Test Project

Use this as the example project structure for screenshots and demonstrations.

```text
Front Matter
├── Title Page
├── Copyright
└── Dedication

Manuscript
├── Part One
│   ├── Chapter One
│   │   ├── Scene 1
│   │   └── Scene 2
│   └── Chapter Two
│       ├── Scene 1
│       └── Scene 2
└── Appendix A

Back Matter
├── Acknowledgments
└── About the Author
```

## Test content to include

Add one of each:

- footnote
- comment
- annotation
- image
- table
- custom metadata field
- styled paragraph
- internal document link
- placeholder
- replacement token

## Why this works

A small controlled project makes Compile easier to teach.

It lets the reader see exactly what happens when:

- a Section Type changes
- a Section Layout changes
- a separator changes
- a placeholder resolves
- a comment is included or removed
- front matter is included or excluded
