# Compile only the Binder Selection

## Fast answer

Compiling the Binder selection exports only the selected item or selected range, useful for small tests and partial deliverables.

## Why this matters


Selection-based compile is one of the fastest testing methods.

Use it when you need:

- one chapter
- one scene
- one appendix
- a small sample
- a format test
- a partial submission
- a proof of a problematic section


## Core workflow


Basic workflow:

1. Select the desired Binder item or items.
2. Open Compile.
3. Choose selection-based compile if available.
4. Review Contents.
5. Confirm layouts.
6. Compile.
7. Inspect output.

For testing, include at least one item before and after the problematic boundary if separator behavior matters.


## Common mistakes


### Forgetting selection context

Make sure the selected Binder item is truly what you intend to export.

### Testing too little

A single scene may not reveal chapter heading or separator problems.

### Assuming partial compile equals full compile

Some front matter, numbering, and context-dependent behavior may differ.


## Practical test

Compile a small sample before compiling the full manuscript. Use one chapter, one scene, one front matter item, and one item that uses the setting being tested.

## Troubleshooting lens

When output looks wrong, ask:

1. Is the correct material included?
2. Is the correct Section Type assigned?
3. Is the correct Section Layout assigned?
4. Is the selected Compile Format the one being edited?
5. Is the output format capable of showing the thing you expect?


## Best uses

Selection compile is excellent for:

- fast layout tests
- checking one chapter opening
- testing footnote behavior
- testing a table
- testing an image
- testing a custom Section Layout

## Warning

Numbering and page behavior may differ from full-project compile because the surrounding context has changed.
